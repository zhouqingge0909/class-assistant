班级助手 · 局域网版（Windows）
================================

不用买云服务器、不用联网：把学校里一台 Windows 电脑当服务器，
老师手机连学校 Wi-Fi、教室一体机连校园网，就能用。

【准备】
  · 一台一直开着的 Windows 电脑（Win7 / 10 / 11，64 位），和教室一体机、老师手机在同一个校园网里。
    办公室电脑、机房电脑都行。
  · 最好请学校网管把这台电脑的 IP 地址固定下来（或在路由器里给它"绑定 IP"）。
    不然电脑重启后地址可能会变，一体机和老师手机就找不到它了。

【第一次使用】
  1. 把压缩包"全部解压"到 D 盘等位置（不要直接在压缩包里双击）。
  2. 双击「启动班级助手」。
     第一次会弹出"你要允许此应用对你的设备进行更改吗"，点"是"（这是让手机和一体机能连上这台电脑）。
  3. 黑色窗口里会显示：
        工作台地址：http://192.168.x.x:8080/
        管理员密码：xxxxxx
     老师手机连上学校 Wi-Fi，用浏览器打开这个地址，用管理员密码登录。
  4. 建班：点工作台顶部的班级选择框 →「＋ 添加 / 管理班级…」，填班级名称和学生名单
     （一行一个名字，可以从 Excel 复制一整列粘贴），点「添加班级」。名单也可以先空着，让班主任以后自己导入。
  5. 装教室一体机（见下面【装教室一体机】）。
  6. 双击「开机自动启动-打开」：以后这台电脑开机、登录 Windows 后会自动启动班级助手。

【装教室一体机】
  在「班级管理」的班级列表里，点这个班的「一体机」按钮，选一体机的系统，复制安装命令。
  一体机不用联网，安装需要的东西都从这台电脑下载。
  · Windows 一体机：按键盘上的 Win+R，粘贴命令，回车。第一次要装 Python，等 1–3 分钟。
  · 麒麟 / 统信（Linux）一体机：打开"终端"（在开始菜单里搜"终端"，或在桌面空白处右键 →"在终端中打开"），
    粘贴命令（终端里粘贴是 Ctrl+Shift+V，或右键 →"粘贴"），回车。
      - 看到"✅ 安装完成"就好了，大屏右边会出现「工具」小把手。
      - 一体机缺少弹窗组件（tkinter）时会自动从这台电脑补装，不用联网、不用 sudo 密码
        （适用于麒麟 V10 等基于 Ubuntu 20.04 的系统，x86 和 ARM 芯片都行）。
      - 补装不上时会提示找有 sudo 密码的人运行：sudo apt-get install python3-tk
  · 装好以后一体机开机会自动运行；这台电脑上的班级助手更新后，一体机 10 分钟内会自动更新。
  · 试一下：在工作台「喊话」里发一句话，看大屏有没有弹出、有没有声音。

【装好以后怎么用】
  · 管理员（装班级助手的人）：建班，在「班级管理」里生成"班主任二维码"发给班主任。
    管理员密码只自己用，不要告诉别的老师。
  · 班主任：用微信扫班主任二维码，填自己的称呼就加入了，不用密码。
    在「班级管理」里生成"任课老师二维码"发到本班老师群；还可以设本班作息时间、课程表。
  · 任课老师：扫任课老师二维码加入，能喊话、布置作业、用课堂工具（计时、抽号、发文件到大屏）。
  · 喊话：在「喊话」里打一句话，比如"请张三到物理办公室"，点发送。
    下课时大屏弹窗 + 语音播报；上课时只在大屏角落提示、不出声；选「紧急」上课也弹大窗。
    打开「定时发送」可以定一个时间发，选了重复（工作日 / 每天 / 星期几）就成了定时提醒。
  · 换手机或在电脑上用：在工作台点右上角小人图标 →「复制登录链接」，在新设备上打开；
    或点「添加到手机桌面」，以后点桌面图标就能打开。
  · 大屏没人用时会自动显示看板：课程表、作业、倒计时、老师留言。

【平时要注意】
  · 黑色窗口不要关（可以最小化）。关了喊话就发不出去。
    班级助手开着的时候，电脑不会自动睡眠（屏幕可以照常关）。
  · 这台电脑关机、断网，大屏就收不到消息；重新开机后会自动恢复。
  · 只能在学校里用：老师在家用手机流量是连不上的。
  · 语音播报用的是电脑自带的中文语音（"慧慧"），不用联网、不花钱。

【数据和备份】
  · 所有数据都在 app 文件夹里：data（班级数据）、config.json（管理员密码等设置）。
    请不要把这两样发给别人。
  · 每天凌晨 3 点后自动备份到 app\backups，保留 30 天。
    也可以在工作台里"导出本班数据"。

【更新到新版本】
  1. 关掉黑色窗口。
  2. 下载新版压缩包，解压后把里面的全部文件复制到原来的文件夹，选择"替换"。
     （data、config.json 不在压缩包里，不会被覆盖，班级数据和密码都会保留。）
  3. 再双击「启动班级助手」。教室一体机会在 10 分钟内自动更新。

【常见问题】
  · 手机打不开工作台：
      - 手机是否连的学校 Wi-Fi（不是流量）；
      - 地址是不是黑色窗口里显示的那个（电脑重启后可能变了）；
      - 有的学校 Wi-Fi 不让手机访问办公电脑，请问一下网管。
  · 提示"端口被占用"：可能已经开着一个了，看看任务栏。
    确实被别的程序占了，就用记事本打开 app\config.json，把 "port": 8080 改成 8090 之类，保存后重新启动。
    （改了端口，一体机要重新运行一次安装命令。）
  · 没有声音：这台电脑可能没有中文语音（英文版 Windows），大屏只响"叮咚"；
    Windows 一体机会用它自己的语音朗读。
