班级助手 · 自己搭一套

跟着做，大约 20 分钟，不需要会编程

班级助手装在你自己的云服务器上。学生名单、作业、考勤这些数据都只存在你的服务器里，作者看不到。

需要准备：

  • 一台云服务器（下面以腾讯云"轻量应用服务器"为例，买最低配置就够了，阿里云等其他云也可以）
  • 教室一体机是 银河麒麟 / 统信 UOS（很多希沃一体机是这种），或者 Windows，都可以。
1

买一台云服务器

  1. 打开腾讯云官网，找到轻量应用服务器，点"新建"。
  2. 地域：选离学校近的。
  3. 镜像：选系统镜像 → Ubuntu 24.04（22.04 也行）。
    不要选"宝塔""WordPress"这类应用镜像。
  4. 套餐：最低配置（2 核 2G）就够用。

付款后等一两分钟，服务器状态变成"运行中"就可以了。

2

打开服务器的命令窗口

在服务器控制台里点这台服务器的"登录"按钮，按提示用网页方式登录。登录后会出现一个黑色窗口，这就是命令窗口。

最好在电脑上操作，手机上不方便粘贴。

3

粘贴安装命令，按回车

复制下面这行，粘贴到黑色窗口里，按回车：

curl -fsSL http://下载地址/dist/setup.sh | sudo bash

黑色窗口里粘贴：点右键选"粘贴"，或者按 Ctrl + Shift + V（Mac 上按 Cmd + V）。

第一次安装大约要等 5 分钟。装好后最后会显示：

============================ ✅ 班级助手已经装好，并会开机自动运行 工作台地址：http://你的服务器IP 管理员密码：一串随机密码 ============================

把工作台地址和管理员密码截图保存好。

4

登录工作台，建班

  1. 用手机或电脑浏览器打开工作台地址，输入管理员密码登录。
  2. 点顶部的班级下拉框，选"＋ 添加 / 管理班级…"。
  3. 填上班级名，比如"高一3班"。学生名单可以一行一个名字粘贴进去，也可以先空着，以后让班主任自己导入。
打不开工作台？到服务器控制台的"防火墙"页面，添加一条规则：协议 TCP，端口 80，允许。腾讯云轻量服务器一般默认已经放行了。
5

在教室一体机上装接收端

  1. 在工作台"添加 / 管理班级"里选中这个班，选一体机系统（麒麟/统信 或 Windows），下面会显示这个班的一体机安装命令，点复制。
    可以用微信或 U 盘把命令传到一体机上。

麒麟 / 统信：在桌面空白处点右键，选"打开终端"（也可以按 Ctrl + Alt + T），粘贴命令（Ctrl + Shift + V），按回车。出现 ✅ 安装完成 就好了。

Windows：按 Win + R，粘贴命令，按回车。第一次会自动下载安装 Python，等 1–3 分钟，出现 √ 安装完成 就好了。

回到工作台给这个班发一句话，大屏弹出来并播报，就说明全部装好了。装好后一体机会开机自动运行，服务器升级时 10 分钟内自动更新；排考或布置听力后音频也会提前预下载到本地缓存，播放时不依赖实时网速。

全校几十个班如果用 VOI 桌面云或开机还原，不用逐班复制命令，见下方常见问题「几十个班用 VOI 桌面云、开机自动还原怎么装？」。

6

邀请同事与放到桌面

在"添加 / 管理班级"里可以生成班主任二维码。班主任扫码加入后，能管本班的全部功能，还可以再发任课老师二维码，邀请各科老师加入。

  • 教多个班的老师：用同一个微信或浏览器分别扫各班二维码即可绑定所有任教班级，在工作台随时切班，或一键开启「同时发多个班 / 同时布置到多个班」（支持喊话、定时提醒、布置作业、大屏留言、发文件、安排考试和播放听力，各班作业可单独修改互不影响）。
  • 把工作台放到桌面：点右上角「我的身份」可下载电脑桌面快捷方式（班级助手.url，双击直接进；管理员为纯网址不含密码）；手机端可点「添加到手机桌面」，或在微信右上角 ··· 收藏、设为浮窗。

老师们扫码就能用，不需要密码。管理员密码只有你自己知道。

常见问题

一体机需要联网吗？

需要，而且要一直联着。一体机每 2 秒向你的服务器问一次有没有新消息，断网就收不到喊话。不过它只需要能连上你自己的服务器，不用登录任何账号。学校网络有限制的话，先用一体机的浏览器打开工作台地址试试，能打开就没问题。断网期间发的消息会在服务器上保留 2 小时，一体机重新联网后会补收。另外，考试听力和课堂听力音频会提前预下载到一体机本地缓存，开播后即使中途断网也不会中断。

怎么放考试听力和平时课堂听力？

考试听力在工作台「大屏」（任课老师为「考试」）排考时直接上传音频，平时训练或全年级广播在「课堂 → 播放听力」使用（支持 MP3 / WAV，上限 80MB，多班共享只存一份，7 天自动清理）。上传后各班一体机在后台静默预下载并校验，工作台实时显示各班「已就绪」进度；支持 10 秒「考前试音」、到点自动或手动同步开播，大屏底部带有低调的暂停 / 重播 / 停止按钮供监考应急。

学校班很多，怎么让各班班主任自己建班？

不用管理员一个个建班发二维码：用管理员密码登录工作台，点左侧「记录」，拉到底部找到「老师自助建班注册」，打开「开放老师自助注册」开关即可（会自动生成注册码，也可以改成好记的）。把注册链接或二维码截图和注册码发到学校老师群，班主任填写后就自动成为该班班主任。全校建完班后关掉开关即可，已建班级不受影响，也不需要改配置文件或重启服务器，已装好的一体机也不用重装。

几十个班用 VOI 桌面云、开机自动还原怎么装？

管理员打开「添加 / 管理班级」，拉到底部展开「VOI 桌面云 / 全校统一安装（按 MAC 自动认班）」，把不含班级和密钥的通用安装命令在母机装一次、同传给全校即可。打开「允许新大屏开机自选班级绑定」后，每台教室大屏开机在屏幕上点一下自己班级就会记住网卡 MAC，以后每次重启还原都会自动认班；全校绑完关掉开关防误点，换教室或换机时在列表里点「解绑」即可。

怎么更新到最新版？

在服务器的命令窗口里，把第 3 步的安装命令再运行一次就行，班级数据不会丢。教室一体机会在 10 分钟内自动跟着更新，不用再去教室。

忘了管理员密码怎么办？

把第 3 步的安装命令再运行一次，最后会重新显示管理员密码。

数据会丢吗？怎么备份？

服务器每天会自动备份一次，保留 30 天。班主任也可以在"记录"栏目里"导出本班数据"，得到一个 Excel 文件自己留存。

作者能看到我们班的数据吗？

看不到。安装包里只有程序，所有数据都存在你自己的服务器上。

不想用了，怎么从一体机上卸载？

远程批量卸载（推荐）：管理员打开「添加 / 管理班级」，拉到底部展开「批量远程卸载一体机（全校 / 多班）」，可单选、按年级选或全选，输入「确认卸载」下发指令——在线一体机几秒内自动卸载，离线机器指令保留 7 天联网自动执行，大屏未确认前随时可点「撤销未确认的卸载」（VOI 学校还可在确认弹窗勾选同步清除 MAC 绑定记录；旧机报废不再联网时直接在上方 VOI 列表点「解绑」即可）。只卸载一体机程序，不会删除服务器上的班级名单、作业和历史数据。

单台手动卸载：在"添加 / 管理班级"选该班，展开安装命令下面的"不用了？卸载一体机上的班级助手"，复制卸载命令在一体机运行即可。删班之前建议先卸载；装了冰点还原或开机还原的电脑，需先解冻或在母盘清理。

一体机安装时提示"下载失败"？

说明一体机没连上网，或者连不上你的服务器。先用一体机的浏览器打开工作台地址试试，能打开再重新运行安装命令。
