班级助手 · 自己搭一套

跟着做，大约 20 分钟，不需要会编程

班级助手装在你自己的云服务器上。学生名单、作业、考勤这些数据都只存在你的服务器里，作者看不到。

需要准备：

  • 一台云服务器（下面以腾讯云"轻量应用服务器"为例，买最低配置就够了，阿里云等其他云也可以）
  • 教室一体机是 银河麒麟 / 统信 UOS（很多希沃一体机是这种），或者 Windows，都可以。
1

买一台云服务器

  1. 打开腾讯云官网，找到轻量应用服务器，点"新建"。
  2. 地域：选离学校近的。
  3. 镜像：选系统镜像 → Ubuntu 24.04（22.04 也行）。
    不要选"宝塔""WordPress"这类应用镜像。
  4. 套餐：最低配置（2 核 2G）就够用。

付款后等一两分钟，服务器状态变成"运行中"就可以了。

2

打开服务器的命令窗口

在服务器控制台里点这台服务器的"登录"按钮，按提示用网页方式登录。登录后会出现一个黑色窗口，这就是命令窗口。

最好在电脑上操作，手机上不方便粘贴。

3

粘贴安装命令，按回车

复制下面这行，粘贴到黑色窗口里，按回车：

curl -fsSL http://下载地址/dist/setup.sh | sudo bash

黑色窗口里粘贴：点右键选"粘贴"，或者按 Ctrl + Shift + V（Mac 上按 Cmd + V）。

第一次安装大约要等 5 分钟。装好后最后会显示：

============================ ✅ 班级助手已经装好，并会开机自动运行 工作台地址：http://你的服务器IP 管理员密码：一串随机密码 ============================

把工作台地址和管理员密码截图保存好。

4

登录工作台，建班

  1. 用手机或电脑浏览器打开工作台地址，输入管理员密码登录。
  2. 点顶部的班级下拉框，选"＋ 添加 / 管理班级…"。
  3. 填上班级名，比如"高一3班"。学生名单可以一行一个名字粘贴进去，也可以先空着，以后让班主任自己导入。
打不开工作台？到服务器控制台的"防火墙"页面，添加一条规则：协议 TCP，端口 80，允许。腾讯云轻量服务器一般默认已经放行了。
5

在教室一体机上装接收端

  1. 在工作台"添加 / 管理班级"里选中这个班，选一体机系统（麒麟/统信 或 Windows），下面会显示这个班的一体机安装命令，点复制。
    可以用微信或 U 盘把命令传到一体机上。

麒麟 / 统信：在桌面空白处点右键，选"打开终端"（也可以按 Ctrl + Alt + T），粘贴命令（Ctrl + Shift + V），按回车。出现 ✅ 安装完成 就好了。

Windows：按 Win + R，粘贴命令，按回车。第一次会自动下载安装 Python，等 1–3 分钟，出现 √ 安装完成 就好了。

回到工作台给这个班发一句话，大屏弹出来并播报，就说明全部装好了。

6

邀请同事

在"添加 / 管理班级"里可以生成班主任二维码。班主任扫码加入后，能管本班的全部功能，还可以再发任课老师二维码，邀请各科老师加入。

老师们扫码就能用，不需要密码。管理员密码只有你自己知道。

常见问题

一体机需要联网吗？

需要，而且要一直联着。一体机每 2 秒向你的服务器问一次有没有新消息，断网就收不到喊话。不过它只需要能连上你自己的服务器，不用登录任何账号。学校网络有限制的话，先用一体机的浏览器打开工作台地址试试，能打开就没问题。断网期间发的消息会在服务器上保留 2 小时，一体机重新联网后会补收。

怎么更新到最新版？

在服务器的命令窗口里，把第 3 步的安装命令再运行一次就行，班级数据不会丢。教室一体机会在 10 分钟内自动跟着更新，不用再去教室。

忘了管理员密码怎么办？

把第 3 步的安装命令再运行一次，最后会重新显示管理员密码。

数据会丢吗？怎么备份？

服务器每天会自动备份一次，保留 30 天。班主任也可以在"记录"栏目里"导出本班数据"，得到一个 Excel 文件自己留存。

作者能看到我们班的数据吗？

看不到。安装包里只有程序，所有数据都存在你自己的服务器上。

不想用了，怎么从一体机上卸载？

在"添加 / 管理班级"里，安装命令下面有"不用了？卸载一体机上的班级助手"，点开复制卸载命令，在一体机上用和安装一样的方法粘贴运行即可。删班之前先卸载。

一体机安装时提示"下载失败"？

说明一体机没连上网，或者连不上你的服务器。先用一体机的浏览器打开工作台地址试试，能打开再重新运行安装命令。
